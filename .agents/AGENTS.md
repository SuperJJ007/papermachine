# AGENTS.md — agent material

This subtree contains durable [Agent Notes](notes/README.md) and reusable [skills](skills/). Product behavior belongs in source, package READMEs, or `docs/`; decisions and rationale belong in Agent Notes; workflows belong in skills.

Temporary plans, handoffs, scratch notes, audit fragments, and generated research inputs live only in the ignored `tmp/agent-work/<task>/` directory. Each temporary task directory names its owner, creation date, and retirement condition. Temporary material is not authority and must not receive inbound links from durable documents.

At task completion, transfer durable facts to the owning current document or Agent Note, then delete the task directory. Preserve historical evidence only when a durable record needs it and place that evidence under the repository's governed evidence or Agent Note hierarchy. Follow [notes/AGENTS.md](notes/AGENTS.md) before changing note lifecycle and the relevant `SKILL.md` before changing a skill.
