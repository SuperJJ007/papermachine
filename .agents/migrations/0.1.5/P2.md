The ordinary local spawn calls childEnv directly, while managed runners materialize targetEnvironment separately. E2B serializes a remote ambient environment into a target environment file and separately builds controlEnvs. All three paths need the explicit target-base choice; changing only the ordinary spawn would leave managed runners or remote targets inheriting ambient values.

BoundProcessOwner.signal currently accepts only SIGTERM/SIGKILL. Cooperative interruption must account for platform owners and target-start timing, not just add a public handle closure.
