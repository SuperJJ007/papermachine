# PaperMachine 0.1.3 / dsh 0.1.5-rc.1 实机验收

本清单针对本次迁移分支的最新本地开发构建。使用隔离验收 home，保留已有 Python/R 环境与验收会话；正式签名安装包、自动升级与平台矩阵不计入本轮产品行为通过。推荐先检查 1–12，再检查恢复与设置。每项记通过/失败，失败附操作、会话名、截图和时间。

## 日常使用：先检查这些

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 打开应用、查看 About、新建工作区和 Science 会话 | 显示 PaperMachine 0.1.3 与内部 dsh 0.1.5-rc.1；无旧品牌、白屏、无限连接；选中的工作区正确。 |
| 2 | 中文输入法输入，粘贴多行文本，修改草稿后发送 | 无吞字、重复发送、旧草稿回填；发送后清空，回复出现在当前会话。 |
| 3 | 发送下面的 Python/R 测试任务 | 两种语言均真实执行，结果与数据一致，图像、表格能打开；不出现环境缺失或不必要重装。 |
| 4 | 同一会话继续询问上轮数据，再另建会话运行 | 同一运行内核状态可继续使用；新会话不借用另一会话变量；内核重启后不虚称变量仍存在。 |
| 5 | 上传/选择一份自己的 CSV、XLSX 或 RDS，要求查看列、缺失值和简单统计 | 通过 Python/R 读取数据，中文列名和文件名正确；工作区原文件未被修改；结果可追溯到输入。 |
| 6 | 在 Chat 中展开/折叠工具过程，观察滚动和步骤统计 | 折叠不隐藏最终答复与成果；展开能看运行代码与结果；新输出不打断正在查看的历史。 |
| 7 | 切换 Chat、Process、Trajectory，展开执行行 | 三种视图对应同一会话；Process 有正确请求、步骤、失败状态、stdout/stderr；Trajectory 可查看记录；切回不乱序。 |
| 8 | 打开已有“Python 和 R 合成数据验收”会话的 Process | 第二轮显示它自己的请求，不能出现“本轮要求不可用”或借用第一轮请求；第一轮启动失败仍保留为失败事实。 |
| 9 | 从消息成果入口与成果库分别打开同一图表、表格、文本文件 | 文件身份与内容一致；无空图、404、串会话；PNG 灯箱打开关闭正常。 |
| 10 | 编辑图表标题/坐标轴/图例，预览后定稿，再查看修改前版本 | 预览与保存一致；产生新版本，旧版内容未覆盖；取消修改不生成版本。版本切换应从提供具体版本的入口检查，成果库 latest-only 入口的禁用按钮不代表新故障。 |
| 11 | 打开成果溯源，查看输入、运行、代码和记录；添加再删除一条测试笔记（入口存在时） | 溯源对应真正产出该版本的步骤；笔记变化可恢复，不伪装为新的模型运行；缺失信息明确表示不可用。 |
| 12 | 同时打开成果库和两个成果标签，分栏、拖动宽度、切换标签 | 原生右侧栏无覆盖和闪退；同一成果标签不串版本；查看 Process 与右侧成果不互相抢焦点。 |

测试提示词（合成数据，不涉及私人文件）：

> 用 Python 生成 x=[1,2,3,4]、y=[2,4,6,8] 的表格，计算 x 的和并绘制折线图；再用 R 独立计算相同的和与均值。报告两种语言各自的结果，保留可查看的图表和数据成果，不修改工作区原文件。

预期：x 的和为 10，均值为 2.5；y 的和为 20，图上四个点为 (1,2)、(2,4)、(3,6)、(4,8)。

## 中断、历史与恢复

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| 13 | 执行中点击停止，等待结束后发送新请求 | 明确停止；按钮恢复；无后台重复答复或永久忙碌；下一次运行可用。 |
| 14 | 运行中追加一条输入，检查队列/引导操作（按界面实际入口） | 普通发送与引导语义明确；普通后续消息不偷偷合并进上一轮；消息不丢失或重复。 |
| 15 | 打开长会话，加载更早历史，在三个视图之间切换 | 早期运行和成果不被算到最新轮；加载历史只补文本，不改变轮次归属。 |
| 16 | 有内容会话：保留两栏、两个成果标签和选中版本，正常退出再打开 | 同一会话、右栏布局、成果内容与选中版本恢复。Process 折叠状态刷新后重置是当前设计，不按丢数据报告。 |
| 17 | 空会话：打开成果库并分栏，退出重开，重复三次 | 标签和分栏稳定恢复。此前这里曾一次丢失，尤其需要记录复现路径；一次通过不能解释历史异常。 |
| 18 | 新建两个工作区并来回切换，关闭再打开其中一个会话 | 工作区、会话目录、成果库范围正确；不串文件、草稿或选择状态。 |
| 19 | 使用旧 Science 会话副本检查打开失败（有现成副本时） | 不支持的旧格式明确报错，原文件不被覆盖或删除，新建 V3 会话仍可用。不要用唯一原件做破坏性测试。 |

## 不应混入本轮验收的功能

上游 dsh 的改进按 PaperMachine 实际组合检查：新版输入与会话生命周期、过程折叠、Trajectory、原生侧栏、设置和日志恢复都在本清单中。Science 组合禁用了或替换了上游通用 shell、普通文件写入、Goal、Plan、Subagent 等入口；不要把原版 dsh 的全部功能都当作 PaperMachine 必须显示的按钮。

签名/公证、DMG/NSIS、Windows 原生适配仍暂缓。远程 CI、完整跨版本 seed 升级和未应用的遥测/workflow 工作属于后续收尾，不用一次 GUI 验收替代。遥测在本地验收启动中关闭。
