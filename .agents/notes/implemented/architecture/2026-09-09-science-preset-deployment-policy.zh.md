# Agent Note: Science 预设部署策略

Status: implemented

[English](2026-09-09-science-preset-deployment-policy.md) | 中文

## 问题

Science 部署需要受限工具、固定预设策略及跨应用界面可见的有效设置。

## Decision

Science 预设组合只读文件系统入口和经过筛选的模型工具。复制资格属于行为元数据，由 Host 写入操作与客户端共同执行。内置元数据缺失或已存在的元数据无效时拒绝复制。MCP 策略在加载时解析，并对每一代发现结果校验。工具结果裁剪可按记录的调用名称豁免承载指令的工具。

## Consequences

设置分别公开脱敏后的已保存值与当前生效值。重启生效的所有者保留注册时的生效值；即时生效的所有者同步更新两者。消息面替换后的请求重试重新记录已保留的运行上下文，不重复执行提供方工作。science-headless 与 Web 配置共享产品预设和 Host 服务。这些策略不增加兼容格式，也不取代本树中的活动实现记录。

## 考虑过的替代方案

只在 UI 限制复制会被直接调用绕过。全局 Host 工具会把能力泄漏到受限预设作用域。
