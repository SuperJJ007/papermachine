# Agent Note: PaperMachine 桌面产品生命周期

Status: implemented

[English](2026-09-10-papermachine-desktop-product-lifecycle.md) | 中文

## 问题

PaperMachine 需要准备科学解释器并恢复用户选择的安装位置，同时不能向应用内容授予包管理或文件系统权限。环境安装与已有的带日志桌面包安装器会在同一产品主目录下停止和重启 Host；相互独立的操作生命周期可能让一个操作在另一个操作修改环境或应用 profile 时重启 Host。

## 决策

保留分帧管道 Host、稳定的 `dsh-app://app` 来源、已安装的 Science bundle，以及支持暂存与回滚的项目管理器。增加由桌面壳持有的首次设置页和恢复页，分别使用独立的沙箱 preload。每个设置或恢复请求都校验具体所属窗口、主 frame 和壳页面。应用内容只获得载体标记。

在浏览器数据、单实例锁、profile 路径和 seed 解包之前解析产品主目录。Desktop 在共享解析器上增加 R 所需的规范路径无空格限制，不改变 CLI 路径策略，也不导入官方 DSH 状态。位置变更需要确认，保留现有文件，保存指针并重启。首次设置窗口先于用户启动的 seed 安装与 Conda 环境准备出现。

一个桌面操作持有安装、环境变更、插件修改和主目录变更的所有权，直到异步工作结束。退出时拒绝新工作、中止环境子进程、等待活动包事务，再停止 Host。健康探测和活动 Host 启动都会重新生成机器专属的 Science 配置。插件暂存保留 profile overlay。校准过程比较完整的本地包集合和每个已安装包版本，因此客户端包缺失及同版本包产物变化都会触发修复。

产品版本独立于内部 Harness 包版本。关于页、首次设置页和产物名称读取同一产品版本 JSON；内部包与 seed 校验仍要求精确一致。POSIX Host 持有独立进程组及由内置 Node 运行的 watchdog。正常退出会等待后代进程及 watchdog；父进程死亡触发进程组回收。watchdog 不删除包事务锁，其 pnpm worker 所有权仍是判断依据。Host 标准错误输出有大小上限，持久化前脱敏，并按打包配置轮转。

开发与打包入口共用资源准备脚本。它复用通过 SHA-256 校验的可执行文件缓存，或下载固定的官方资源，不接受调用者提供的下载 URL。产品资源包含环境声明和技能；Windows 资源还包含固定的应用本地运行库。遥测配置随产品提供，但主进程不发送事件。

Desktop 要求显式的 `papermachine` 客户端构建配置。构建记录将其标题和配置绑定到提交、内部包版本及完整客户端产物摘要。开发与打包都会验证该记录；跳过构建时不能消费因常量折叠而删除 PaperMachine 注册的官方产物。Desktop 通过共享 tarball 校验准备本地 seed 包，不生成 npm 发布顺序清单。官方发布打包仍要求精确的 official 配置。

Seed 制备使用内置 Node.js 在一次性主目录中启动每次离线安装的 Host 组合，并在归档 store 前核对发布版本。仅检查包文件不足以证明运行时可用：pnpm 可能跳过下载失败的可选原生依赖，却报告安装成功。探测在成功和失败时都会等待 Host 退出并清理主目录。

## 考虑过的替代方案

用早期 HTTP 启动器替换上游壳会丢失稳定来源的客户端状态和事务式包升级。将 Science 作为普通用户插件安装会使产品本身可被移除。向首次设置页提供插件管理器 preload 会扩大 renderer 在环境设置之外的权限。只用发布版本号判断是否修复，会遗漏内部发布版本相同但客户端包集合发生变化的情况。

## 影响

开发项目链接已构建的工作区，并跳过 seed 应用。其运行时与 UI 结果不能证明 seed 或已安装 profile 的验收完成。macOS seed 准备入口要求 Developer ID 签名，没有受支持的免签名准备模式，打包在准备阶段结束时也不例外。

会话文件保留在共享产品主目录下，桌面设置、修复或位置选择均不改写它们。持久化读取器负责兼容性判断。环境声明、绑定校验、取消、源回退、自定义包验证和暂存 overlay 测试覆盖非会话设置行为；主入口测试验证窗口顺序、IPC 拒绝、重试、恢复和退出竞争。watchdog 进程测试使用真实源码入口与 tsx 的 ESM hook，并等待进程清理完成。

既有的 [Electron 打包与更新记录](2026-08-25-electron-desktop-packaging-and-updates.zh.md) 继续负责字节传输、签名 seed 校验、回滚和包隔离。[安装隔离记录](2026-09-10-papermachine-installation-isolation.zh.md) 继续负责共享主目录解析器及与官方 DSH 的分离。本记录补充桌面专属 R 限制和环境生命周期，不替代这些决定。平台签名、安装包矩阵和真实产品验收需要独立证据。
