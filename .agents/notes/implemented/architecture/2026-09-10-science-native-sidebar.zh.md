# Agent Note: Science 视图使用原生 Sidebar 与对话服务

Status: implemented

[English](2026-09-10-science-native-sidebar.md) | 中文

## 问题

Science 需要项目产物、精确版本编辑与溯源，同时避免维护第二套对话外壳、文件浏览器或停靠系统。持久化标签必须在渲染前恢复资源，异步动作必须保留其来源会话。

## 决策

Science 插件注册 `science-artifact` 资源身份以及原生标签类型、正文和标题。稳定地址包含产物 id；导航参数与会话选择状态保存版本。授权 Science Remote 提供当前元数据与字节。项目产物库拥有 `science-library` 页面、正文与标题，并贡献原生 guide 入口；工作区文件使用上游 Files 与文档查看器。独立页面保留内建 guide，并确保 Files 同时贡献 guide 入口时仍可访问产物库。选择存储不持久化业务元数据。

原生 Sidebar 按会话持久化布局并同步接管恢复的资源实例。布局包持久化右栏宽度。存储持久化将已保存字段与初始默认值合并，排除声明的临时字段。每个产物面板独立持有溯源与灯箱状态；Process 展开状态在同一会话切换平级视图时保留。

Process 与 Trajectory 是平级对话视图。Science 使用公开的输入 dock、标题栏工具区、轮末、工具视图、标签菜单注册及侧栏底部入口。空白会话在首条消息之前已有身份；没有会话时不渲染右栏动作。原生 Turn Process Folding、上下文可见性和轮次统计继续负责 Chat 呈现。

可释放的提交处理器在普通 prompt 传输之前接管暂存的产物编辑，失败时保留选择。按会话寻址的导航保留来源会话。来源专属 Chat 定义渲染已记录的编辑指令及精确版本引用，不显示模型执行上下文。普通会话召回投影保留其他来源拥有的标签。共享灯箱位于 UI primitives，JSON 摘要位于 util-values，避免功能插件之间的运行时导入。

## 考虑过的替代方案

重新应用私有 Details 与嵌套轨迹槽位会重复上游职责并增加后续冲突成本。全局产物版本 URL 会把每次修订变成独立文档。持久化库事实会恢复过期业务数据。真实浏览器场景支持上游折叠行为，因此永久抑制对话会不必要地隐藏原生控件。

## 后果

D9 保持 effective 设置值必填。P4 不改变 Host 授权、旧 Session 拒绝策略或桌面打包。源码组件、公开服务回归及八组真实 Chromium 场景覆盖此次迁移；验收记录列出实际执行检查与剩余迁移阶段。跨会话库预览仅提供最新版本；精确历史版本导航依赖当前会话投影。
