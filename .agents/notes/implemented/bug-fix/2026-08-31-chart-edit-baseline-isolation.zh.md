# Agent Note: 保存版本的基线隔离图表预览与导出

Status: implemented

[English](2026-08-31-chart-edit-baseline-isolation.md) | 中文

## 问题

捕获相对文件名只能在其产出运行内标识图对象。两次模型运行可以向同一文件名保存不同布局，而人工编辑只携带确切父版本和累计操作。选取最早匹配的文件名会编辑错误的图对象。不保留原裁剪或尺寸的重新导出，会在请求操作之外改变图片。对共享可变图对象应用预览，还会使已放弃的操作进入后续提交的 PNG，却不出现在操作日志中。

## 决策

运行时选取所请求产物最近的运行产出版本，并验证其图对象键。这遵循会话不变量：每次人工编辑都以同一产物的当前版本为父版本。较新的来源无法直接编辑时，不能仅因文件名相同就回退到较旧的可编辑图对象。

保存拦截保留图对象和有效导出设置的私有快照。Python 一起复制图对象与相关保存 artist，复制期间暂时解除其管理器关联，避免 matplotlib 登记第二个 pyplot 图对象。快照同时保留保存时的渲染默认值。R 将图对象及其解析后的主题序列化，并保留 `ggsave` 内观察到的尺寸、设备、背景与设备参数。这些快照只保存在内存中，受现有运行保留数量限制；它们不是持久对象格式。

每次预览和保存都会渲染一个新副本，依次应用已提交操作和新操作。热路径与冷路径发送相同的累计列表。无法重建已提交操作时拒绝请求；新操作中的部分失败保留相对于本次请求的索引。预览不会修改基线，发布失败也不会推进基线。只改变文字时，既有文字对象保留原样式。Matplotlib 会把成功的 figure-wide 字体操作记录在该私有图对象副本上，因此从已提交导出重新抽取的目录会报告请求的字体族与字号，而不是从任意标题 artist 采样编辑前默认值；ggplot2 则从更新后的 plot theme 推导相同的导出后值。

这项决策明确了更广泛的[活图编辑设计](../../proposed/architecture/2026-08-28-science-live-figure-editing.zh.md)中的保存版本渲染规则；元素目录、模型引用和查看器所有权仍是该设计中的独立决策。[元素标识冲突决策](2026-08-28-chart-element-id-collision.zh.md)继续适用，未被取代。

冷源码恢复使用独立解释器和操作范围内的取消；[冷回放决策](2026-08-31-science-cold-replay-isolation.zh.md)拥有分析状态隔离与清理语义。

图形序列化恢复逻辑 DPI，但保留复制的显示变换。导出前，副本把该变换归一到自身逻辑 DPI；只改元数据无法修正栅格尺寸。主标题与副标题具有独立操作身份，包括 ggplot2 的两个 null-axes 目标，避免待存编辑合并时丢弃任何一项。全 axes 操作遍历全部目标，不因更早的目标成功而停止。

## 考虑过的替代方案

**选择最新匹配的文件名。** 这仍可能绕过缺少可寻址图表状态的较新来源。必须先按版本溯源选择来源，再检查可寻址性。

**修改并撤销活图对象。** 逆操作必须在成功、失败和取消时恢复所有受影响的 artist 与渲染器状态。复制保存基线，使隔离不依赖不断扩展的撤销实现。

**每次预览都重新执行源码。** 这会在每次防抖编辑时重复科学计算和源码副作用。私有源码恢复仅用于已过期的登记；保留的快照支持热渲染。

## 影响

复制和重新应用已提交操作增加了每次预览的工作量，但使结果不受预览历史和内核冷热状态影响。无法复制的自定义图对象保留有效 PNG，并失去直接可寻址性，而非导致科学运行失败。紧裁剪仍会受文字范围变化影响；保留导出设置并不保证任意编辑都具有相同尺寸。冷回放仍依赖可重现的源码输入和兼容的绘图依赖。

## 验证

运行时回归覆盖多次产出运行、连续人工编辑、冷热路径上的累计操作，以及无法重建已提交操作时的拒绝。可选的 `chart-fidelity.spec.ts` 使用真实 Python/R 内核和产品沙箱，把编辑 PNG 字节与直接源码渲染比较，再检查放弃预览、保存设置、文字样式、保存后的对象修改，以及热预览、冷预览和保存结果的一致性。可运行的 headless Science 快照通过 Loader 组合固定预览隔离与已提交操作上下文。
