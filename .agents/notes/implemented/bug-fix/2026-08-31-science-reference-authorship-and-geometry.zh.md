# Agent Note: Science 引用保留用户身份与导出几何信息

Status: implemented

[English](2026-08-31-science-reference-authorship-and-geometry.md) | 中文

## Problem

Science 编辑记录为 `user/message`，其 `source.kind` 为 `science-edit`。若将所有非 `user` 来源都视为注入上下文，Science 隐藏过程细节时就会隐藏用户提交的指令，语义轨迹也会缺少请求。标注名称缺少文字、颜色代表类别或导出裁剪使坐标失效时，元素引用也难以区分。R 的 PNG 设备导出可能绕过 `ggsave`，保留可变图形对象则可能让预览影响后续编辑。

## Decision

生产者在现有 conversation event 注册表上注册用户输入投影。通用 Chat 和 Detailed Trajectory 使用投影后的指令与引用，并保留日志来源和 Turn 位置。未知来源仍是上下文；卸载生产者会重建已加载投影。Science 自己注册其来源类型，并覆盖历史消息，无需改写日志或在通用 UI 中加入 Science 分支。

每张 PNG 都提供框选。元素行、composer 引用和已发送引用共用可读名称；标注文字、希腊字母和重复项后缀区分目标，同时保持线上 id 稳定。已记录的颜色对应图中内容，悬停或聚焦时高亮可用的导出范围。缺少范围时明确保留框选。未保存的预览禁止新增引用，因为预览没有可引用的持久版本。

Matplotlib 在最终导出绘制期间捕获元素范围，包含 tight 裁剪，并把重复 id 解析到各自的 artist。R 捕获打印到 PNG 设备的一张完整 ggplot，并保留尺寸、DPI、设备和字体选项。构建后的坐标轴标签进入目录，命中范围的 id 必须属于该目录。R 组合图与基础绘图仍仅支持栅格编辑。[编辑基线隔离决策](2026-08-31-chart-edit-baseline-isolation.zh.md) 负责保存快照、绘制默认设置和累计编辑重放；导出几何信息与 PNG 设备捕获使用同一组快照。

## Alternatives considered

**把所有 `user/message` 都视为用户输入。** 拒绝，因为插件也通过此事件记录模型上下文。生产者注册保留了这一区分，不让通用 UI 依赖 Science。

**按颜色重命名目标或把标注与系列合并。** 拒绝，因为相同颜色不能证明共同归属。名称描述各自的目录元素；id 与版本校验仍是权威依据。

**根据未裁剪图形估算裁剪后的坐标。** 拒绝，因为布局和裁剪可能改变导出变换。位置必须描述实际保存的 PNG。

## Consequences

Science 插件加载后，历史日志中的引用消息恢复可见。旧 PNG 的元数据不变：没有命中表的版本使用框选，新支持的结构化位置需要再次导出。系列范围可能覆盖整条曲线；它不表示重叠的填充或图例项都属于同一元素。

注册表、对话和查看器测试覆盖投影重新加载、释放、可读引用、预览引用限制与像素归一化。真实 Python/R kernel 场景覆盖导出快照、重复标注位置、设备捕获和预览隔离。组装后的 Web 场景记录带引用的第二轮输入及其重新加载结果。[元素 id 决策](2026-08-28-chart-element-id-collision.zh.md) 继续负责唯一性；本决策负责导出位置和引用展示。
