# Agent Note：Science 查看器请求跟随当前内容

Status: implemented

[English](2026-08-31-science-viewer-lifecycle.md) | 中文

## 问题

同一查看器会展示不同文件与产物版本。保留上一文件的错误会遮住下一文件；把放大功能放在可编辑分支内会排除跨会话图片；预览响应后重新创建回调则会重复调度同一次编辑。

## 决策

工作区文件预览按路径挂载。当前路径变化时，先清除上一份结果及其错误，再开始新的读取；挂载结束后才到达的响应不能替换当前文件。成功读取和失败读取遵循相同的生命周期。

产物查看器统一持有所有 PNG 的工具栏灯箱，包括其他会话生成的项目文件库产物。灯箱以不可变版本标识为键，其可用性不依赖当前会话是否能编辑产物。

图表的产物、版本及注入的传输函数不变时，预览回调保持身份稳定。发布返回的预览图不能重新启动编辑面板的防抖计时。只有待应用操作或其目标版本变化时才请求新的预览。这与 Runtime 的[已保存版本基线隔离](2026-08-31-chart-edit-baseline-isolation.zh.md)互补：后者负责渲染内容，不负责浏览器请求调度。

## 考虑过的替代方案

只重置成功读取的内容，会把失败读取的错误留给下一路径。单独为文件库增加灯箱，会重复实现查看器的版本选择及关闭行为。从防抖依赖中移除回调，则无法观察传输函数或目标的有效变化。

## 影响

返回某一文件时会重新读取。文件库和可编辑查看器共用放大状态，但不会向文件库产物授予编辑权限。操作或目标变化时，预览请求仍可取消。

## 验证

组件测试覆盖成功或失败后的直接文件切换、迟到响应、跨会话放大与关闭，以及标题编辑完成后的单次请求。组装浏览器夹具通过已挂载的 Science 服务验证文件标签导航、共享灯箱和预览 RPC。
