# Agent Note: 轨迹中的 Science 过程步骤

Status: implemented

[English](2026-08-30-science-trace-process-view.md) | 中文

## 问题

一轮的语言计数和失败总数无法展示分析如何走到结果。分析者需要看到尝试顺序、失败位置，以及哪个调用产出了文件。重复视图标题或把环境显示为 agent 工作，都不能提供这些信息。

## 决策

「过程」是轨迹内部默认的 Science 视图，slot id 为 `process`，「详细」排在后面。保留用户要求行。使用单左轨与通栏卡片，人工改图用用户图标和蓝色左边框区分。四个结构化行分别容纳要求、有序调用标记、右对齐的统计与展开控件，以及每个产物的最终版本标签，不附加自由文本说明。展开后显示步号、种类标记、结构化标题、结果和调用所属的产物版本。标题原位展开所代表的调用；产物标签在文件查看器中打开精确版本，不选择「详细」。点击轮卡片的要求或背景可切换展开，原生展开按钮支持 Enter 与 Space。独立控件和整个输入输出区域，包括标题、状态文字及空白，保留自身点击、滚动和文本选择。轮次与调用的本地展开状态在子视图切换后保留。

标题只取自工具名、经校验的参数字段和 Science 投影事实。不从模型散文或代码推断意图。运行显示原始代码首行预览，合并的资料行列出成员标题。文件标题仅显示 basename。显式调用详情展示记录的代码、输入参数和结果，分列可识别的运行 stdout/stderr，并报告已记录的内核、环境修订、失败代码、字节数和截断标志。代码、任意参数及输出分别采用产物文本显示上限，提供可见截断提示与有界滚动。非文本块仅报告数量和类型，不序列化附件数据。日志中的原始路径只在显式输入详情中可见；视图不读取仅宿主可见的环境字段。JSON 无效或不完整时保留工具名，不虚构缺失事实。run 记录决定运行状态与时长；其他失败由工具结果错误标志判断，缺失结果保持未知。

只在同轮内合并连续未失败的资料查看调用，允许跨 assistant 步号合并。每个成员保留自己的标题、锚点和步骤条标记。运行、标注、发布、委派和失败均保持独立。统计计算包含调用的不同步号，包括合并行内部步号，但不含纯回答步骤；并行调用仍各有标记。步号保留 agent 的真实步序，中间步骤没有工具调用时可能不连续。步骤条最多渲染 120 个标记，限制密集卡片的渲染量，但不裁剪展开清单。

用内核生命周期标记取代环境卡，因为启动与退出有权威时间，并能说明解释器变量是否保留。终态 epoch 保留启动时间，因此回放能展示两端。标记位于包含其时间戳的轮次之前，包含起止时刻；尚未结束的轮次没有时间上限。轮次之外的标记位于之后开始的第一轮之前，否则位于最后一轮之后。这使首次运行期间启动的内核显示在该轮之前，而不是退出之后。环境可用时启动标签显示当前环境名。

本决策部分取代[Science 轨迹与对话信息架构](2026-08-25-science-trajectory-and-transcript-ia.zh.md)中的卡片摘要和子视图名称。其轨迹内嵌位置、已访问面板保留、对话内容归属和轮末产物的理由仍有价值。[Science 对话过程装饰抑制](2026-08-25-science-transcript-chrome-suppression.zh.md)继续负责对话装饰；这两份记录仍保留其独立决策。

保留的运行及产物原本必须有已加载的来源调用才能归属请求。[冷启动分页后仍保留 Science trajectory 归属](../bug-fix/2026-09-02-science-cold-trajectory-ownership.zh.md)部分取代这条规则：Science projection 现在负责完整 trajectory 的 turn、step 与 tool-call identity，已加载的 conversation node 只为调用补充参数、结果与请求文本。确实缺失 projection 坐标的记录仍为 unassigned；回退到最新轮次会伪造来源并抬高该轮耗时与产物数量。标注调用不能确定运行产出版本的生产轮次。

## 考虑过的替代方案

**保留 Science 专用浅色调色板。** Science 成为产品默认模式后，preset 专用的文档配色会抵消应用偏好。保留它会让主题按钮只改变存储状态，而不改变工作台。

**按版本最近的工具调用 id 归属文件。** 标注会替换该 id，却没有产出新文件。行与轮次归属均通过 `runId` 找到生成调用；只有没有运行来源的版本使用自己的工具调用 id。运行记录缺失时，版本留在摘要中，不虚构生成行。内核锚点标识语言、epoch 和生命周期事件，不共用最后一条 Science 事件序号。

**保留两侧主体泳道与三行卡片。** 半宽卡片和挤在步骤条旁的统计会把短调用序列折成矩阵。通栏卡片与独立统计行保留阅读顺序；人工改图卡仍明确标识主体。这部分取代[Science 工作台 UI 收敛](2026-08-23-science-workbench-ui-convergence.zh.md)的主体布局，其输入区与设置决策仍有价值。

**只保留汇总计数。** 计数隐藏尝试顺序、读取失败和文件出现的时点。它适合放在步骤条旁，但不能替代步骤条。

**用模型散文或解析代码解释步骤。** 这会重复对话，或推断结构化事实无法保证的意图。原始代码预览和按需显示的日志输入输出提供证据，不赋予代码意图。

**保留独立环境卡。** 静态 profile 摘要不能说明执行了什么工作。生命周期标记在记录的时间说明可观察事件及其对变量的影响。

**把过程检查跳转到「详细」。** 这会使读者失去当前位置，让紧凑视图依赖工程账本。本地输入输出展开保留上下文，「详细」仍是可选的独立视图。

**每次资料查看都独占清单一行。** 长串读取会淹没运行与失败。连续未失败的调用可共用一行，同时保留独立步骤条标记与导航锚点。

## 验证

### 应用主题

Science 浅色覆盖源于独立 preset 的白色文档工作台。Science 成为产品默认模式后，这一区分消失：即使主题状态和 document 属性正常更新，覆盖仍会遮蔽每一个解析后的深色调色板。AppFrame 没有 Science 调色板覆盖。侧边栏、对话、过程视图和产物库继承应用偏好；只有图片保留既有的固定浅色画布 token，使科学图表在不反色或变暗的情况下保持可读。

这部分取代[Science 工作台 UI 收敛](2026-08-23-science-workbench-ui-convergence.zh.md)中的浅色配色决策。保留该记录独立的输入区、设置与部署配置理由。真实 Science 会话 Web 场景针对渲染后的背景验证深色、浅色和跟随系统操作，而不只检查 body 主题属性。

标记使用两种状态色加中性形状：柔和绿色运行与红色失败、浅中性普通调用、空心标注方块和实心发布圆点。步骤条与清单共用标记样式。结果文字不重复状态圆点，成功使用辅助文字色，失败使用红色。蓝色只用于选中与人工改图，使失败成为唯一高饱和状态色。

- 有序步骤条和展开行与冷回放一致，包括并行调用、资料合并、失败和产物中间版本。
- 折叠卡片不展示执行详情；显式本地详情仅显示已记录的调用内容。无效参数仍可阅读，但不被当作经校验的字段。
- 统计使用记录的步骤、运行和去重产物，内核标记保留终态 epoch 的两端。
- 组件测试覆盖源代码、任意参数和结果的显示上限，以及详情区域点击保护。keyless 真实 Web 组合固定折叠、展开与详情输出，并覆盖宽窄布局下的 Enter/Space、卡片背景与子控件、文本选择、每种调用、精确版本文件及子视图状态保留。

## 后果

即使 conversation 分页省略了对应 node，projection 仍包含完整的 turn 与 call 索引。因此过程视图能保留 step number 和从工具名导出的标题，但请求文本、参数与结果仍需等到对应 node 加载后才可用。内核标记位于轮次之间，不位于逐次调用之间。环境标签使用 projection 中的当前 profile，不重建环境历史。长步骤条和产物标签可跨越一个物理文本行，但保留四个结构化行，不附加自由文本说明。

嵌套 subagent 子泳道、装包与人工操作条目、展开状态落盘仍然延后。委派显示一行调用并提供本地日志输入输出详情；装包与人工操作条目需要权威持久化事件。展开和高亮只属于当前挂载视图，不进入产物选择存储和会话日志。
