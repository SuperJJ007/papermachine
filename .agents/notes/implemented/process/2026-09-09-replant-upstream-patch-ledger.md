## Desktop Host pipe ownership

Host shutdown gives each inherited byte-pipe descriptor one owner: its Node fs stream. Explicit stream destruction closes the descriptor even when `autoClose` is false, so shutdown awaits `close` instead of also calling `closeSync`; a second close can fail with EBADF or close an unrelated resource that reuses the descriptor number. Electron closes its request writer to release the Host's pending read. Response writes finish before their stream closes, and close failures remain errors. Regression coverage uses real inherited pipes and verifies repeated shutdown, completed response bytes, and propagated close failures.
