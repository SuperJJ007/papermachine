# Agent Note: 轨迹中的 Science 过程步骤

Status: proposed

[English](2026-08-30-science-trace-process-view.md) | 中文

## 问题

一轮的语言计数和失败总数无法展示分析如何走到结果。分析者需要看到尝试顺序、失败位置，以及哪个调用产出了文件。重复视图标题或把环境显示为 agent 工作，都不能提供这些信息。

## 提案

用「过程」作为轨迹内部默认的 Science 视图，slot id 为 `process`，「详细」排在后面。保留用户要求行。使用单左轨与通栏卡片，人工改图用用户图标和蓝色左边框区分。四个结构化行分别容纳要求、有序调用标记、右对齐的统计与展开控件，以及每个产物的最终版本标签，不附加自由文本说明。展开后显示步号、种类标记、结构化标题、结果和调用所属的产物版本。标题跳转到该行代表的第一个调用，产物标签打开精确版本。

标题只取自工具名、经校验的参数字段和 Science 投影事实。不解析模型散文或代码，代码和 stdout/stderr 都不进入过程视图。文件参数仅显示 basename。JSON 无效或不完整时保留工具名，不虚构缺失事实。run 记录决定运行状态与时长；其他失败由工具结果错误标志判断，缺失结果保持未知。

只在同轮内合并连续成功的资料查看调用，允许跨 assistant 步号合并。每个成员保留自己的标题、锚点和步骤条标记。运行、标注、发布、委派和失败均保持独立。不同的 assistant 步号决定步骤总数；并行调用仍各有标记。步骤条最多渲染 120 个标记，限制密集卡片的渲染量，但不裁剪展开清单。

用内核生命周期标记取代环境卡，因为启动与退出有权威时间，并能说明解释器变量是否保留。终态 epoch 保留启动时间，因此回放能展示两端。标记位于包含其时间戳的轮次之前，包含起止时刻；尚未结束的轮次没有时间上限。轮次之外的标记位于之后开始的第一轮之前，否则位于最后一轮之后。这使首次运行期间启动的内核显示在该轮之前，而不是退出之后。环境可用时启动标签显示当前环境名。

本提案部分取代[Science 轨迹与对话信息架构](../../implemented/feature/2026-08-25-science-trajectory-and-transcript-ia.zh.md)中的卡片摘要和子视图名称。其轨迹内嵌位置、已访问面板保留、对话内容归属和轮末产物的理由仍有价值。[Science 对话过程装饰抑制](../../implemented/feature/2026-08-25-science-transcript-chrome-suppression.zh.md)继续负责对话装饰；本提案不修改这两份记录。

## 考虑过的替代方案

**保留两侧主体泳道与三行卡片。** 半宽卡片和挤在步骤条旁的统计会把短调用序列折成矩阵。通栏卡片与独立统计行保留阅读顺序；人工改图卡仍明确标识主体。这部分取代[Science 工作台 UI 收敛](../../implemented/feature/2026-08-23-science-workbench-ui-convergence.zh.md)的主体布局，其输入区与设置决策仍有价值。

**只保留汇总计数。** 计数隐藏尝试顺序、读取失败和文件出现的时点。它适合放在步骤条旁，但不能替代步骤条。

**用模型散文或解析代码解释步骤。** 这会重复对话，或推断结构化事实无法保证的意图。「详细」继续负责原始调用与输出。

**保留独立环境卡。** 静态 profile 摘要不能说明执行了什么工作。生命周期标记在记录的时间说明可观察事件及其对变量的影响。

**每次资料查看都独占清单一行。** 长串读取会淹没运行与失败。连续成功的调用可共用一行，同时保留独立步骤条标记与导航锚点。

## 验收标准

标记使用两种状态色加中性形状：柔和绿色运行与红色失败、浅中性普通调用、空心标注方块和实心发布圆点。步骤条与清单共用标记样式。结果文字不重复状态圆点，成功使用辅助文字色，失败使用红色。蓝色只用于选中与人工改图，使失败成为唯一高饱和状态色。

- 有序步骤条和展开行与冷回放一致，包括并行调用、资料合并、失败和产物中间版本。
- 标题及渲染文本不暴露宿主文件路径、代码、模型散文或工具输出；无效参数仅保留工具名。
- 统计使用记录的步骤、运行和去重产物，内核标记保留终态 epoch 的两端。
- 在真实 Web 组合的宽窄布局下，展开、调用导航和精确产物版本导航均可用。

## 风险

投影可能包含调用头位于当前对话窗口之外的运行或产物。过程视图能展示保留的产物事实，但无法重建缺失的步骤标题。内核标记位于轮次之间，不位于逐次调用之间。环境标签使用投影中的当前 profile，不重建环境历史。长步骤条和产物标签可跨越一个物理文本行，但保留四个结构化行，不附加自由文本说明。

嵌套 subagent 子泳道、装包与人工操作条目、展开状态落盘仍然延后。委派只显示一行调用并跳转「详细」；装包与人工操作条目需要权威持久化事件。展开和高亮只属于当前挂载视图，不进入产物选择存储和会话日志。
