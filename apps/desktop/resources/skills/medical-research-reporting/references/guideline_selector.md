# Which reporting guideline?

Use the current official statement for new manuscripts. Historical editions remain available for papers that already committed to them.

| Design | Current official statement | Historical / extensions |
|---|---|---|
| Randomized trial | **CONSORT 2025** (30-item checklist; Hopewell et al. *BMJ* 2025;388:e081123) | CONSORT 2010 (25 items) for already-committed reports. Extensions: cluster, non-inferiority, pilot, CONSORT-PRO, CONSORT-AI, harms content now partly in the 2025 core |
| Trial protocol | SPIRIT 2025 (aligned with CONSORT 2025) | SPIRIT 2013; SPIRIT-AI |
| Observational (cohort, case-control, cross-sectional) | STROBE 2007 | STROBE-ME, RECORD, STROBE-nut, STROBE-MR |
| Systematic review / meta-analysis | PRISMA 2020 (27 items + subitems) | PRISMA-DTA, PRISMA-NMA, PRISMA-IPD, PRISMA-ScR |
| Diagnostic accuracy | STARD 2015 | STARD-AI |
| Prediction model (regression or ML; development, evaluation, or update) | **TRIPOD+AI 2024** (27 main items, 52 subitems; Collins et al. *BMJ* 2024;385:e078378). TRIPOD 2015 is superseded and should no longer be used | TRIPOD-Cluster; TRIPOD-LLM (LLM studies, not generic prediction) |
| Animal pre-clinical | ARRIVE 2.0 Essential 10 | Recommended Set |
| Case report | CARE | — |
| Economic evaluation | CHEERS 2022 | — |
| Quality improvement | SQUIRE 2.0 | — |
| Qualitative | COREQ / SRQR | — |
| Mediation | AGReMA | — |

## Official scope notes (do not collapse these)

- **CONSORT 2025** covers reporting of randomised trials, with emphasis on the two-group parallel design. It is not SPIRIT (protocols), not STROBE (observational), and not a statistical analysis plan.
- **TRIPOD+AI** covers studies that develop, evaluate (validate), or update a multivariable prediction model for diagnosis, prognosis, monitoring or screening, using regression or machine learning, in any medical domain. It does not prescribe how to build a model. A local working map of the 27 main items is not the fillable publisher checklist (Supplementary Table 2) and is not certification.

Source: EQUATOR Network (equator-network.org) and the primary publications above. Always re-read the target journal's required edition before submission.
