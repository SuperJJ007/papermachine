# PRISMA 2020 flow and GRADE

## PRISMA flow counts to report
Records identified (databases, registers, other) → duplicates removed → records screened → excluded → reports sought → not retrieved → reports assessed for eligibility → excluded with reasons (list) → studies included → reports included.

## GRADE certainty per outcome
Start: RCTs = high, observational = low. Downgrade one/two levels for: risk of bias, inconsistency (I² > 50%, non-overlapping CIs, PI crossing null), indirectness, imprecision (CI includes both appreciable benefit and harm; OIS not met), publication bias. Upgrade (observational) for large effect (RR > 2 or < 0.5), dose-response, plausible confounding reducing effect.
