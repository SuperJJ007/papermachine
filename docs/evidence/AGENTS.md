# AGENTS.md — dated evidence

This directory stores dated version, artifact, runtime, platform, and acceptance snapshots. Name a record `YYYY-MM-DD-<scope>.md`; include the investigated repository or artifact, exact SHA/tag/version/hash, date, platform, commands or source links, and bounded result.

Separate observed facts, inferences, recommendations, and unverified items. A source PASS does not prove a built package, installer, signing, installed runtime, Python/R environment, platform, or release PASS. A later revision inherits no earlier result without an exact-identity argument and the required rerun.

Evidence is historical and never the owner of current architecture or future plans. Link to the owning architecture, subsystem, package README, or Agent Note instead of restating it. Correct a factual error explicitly; do not rewrite a snapshot into current status. Follow [../AGENTS.md](../AGENTS.md) for prose, links, pairing, and validation. `CLAUDE.md` is a symlink to this file.
