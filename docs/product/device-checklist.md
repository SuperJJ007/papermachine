# PaperMachine device checklist

English | [中文](device-checklist.zh.md)

The master on-device acceptance checklist for the PaperMachine desktop DMG. Every item carries a stable `<area>.<item>` id so a [release record](../releases/README.md) can cite results against exact items instead of restating them; an id, once assigned, is never reused for a different check. New items are appended to the end of their area rather than inserted between existing ids, which is why an area's ids are not always in the order the items would naturally read.

A release picks between two ways to run this checklist: **full** — every item, in order — for the first on-device pass of a build or whenever unsure, and **delta** — a targeted subset — when re-verifying a specific set of fixes: the items that failed or were partial in the previous release's device pass, any items newly added since then, and a short regression sample of previously-passing items in the areas the change touched. [0.1.1-rc.3.md](../releases/0.1.1-rc.3.md) ran the full checklist; [0.1.1-rc.4.md](../releases/0.1.1-rc.4.md) ran a delta built from rc.3's own results. The **First added** column names the release each item entered this checklist; it does not track when an item's expected result last changed — this page always states the current expected behavior, and a release record's own 改了什么 section is where a behavior change is explained.
