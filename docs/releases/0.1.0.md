# 0.1.0

English | [中文](0.1.0.zh.md)

`0.1.0` is the first public PaperMachine release. It is the [0.1.1-rc.4](0.1.1-rc.4.md) candidate (`codex/rc4-release-candidate`, DMG build commit `d65d2115c1` plus this docs change) with the fixes below on top; see [0.1.1-rc.3](0.1.1-rc.3.md) and [0.1.1-rc.4](0.1.1-rc.4.md) for the candidate chain's own history.

## 改了什么

### 修复

- **Chart-edit font aliases, save-as/annotate turn attribution and data-loading guidance, and kernel stdin/install-timeout handling.** These three fixes shipped in the rc.4 candidate this release is built from: [chart-edit font alias resolution and the titleless-figure Title row](../../.agents/notes/implemented/bug-fix/2026-09-03-chart-font-alias-and-title-row.md), [viewer-write turn attribution and data-loading prompt guidance](../../.agents/notes/implemented/bug-fix/2026-09-03-science-viewer-write-turn-attribution-and-data-loading-guidance.md), and [kernel stdin error handling and honest install-timeout reporting](../../.agents/notes/implemented/bug-fix/2026-09-03-science-kernel-stdin-error-and-install-timeout.md) — see [0.1.1-rc.4](0.1.1-rc.4.md)'s 修复 section for the tested detail.
- **Bundled Science skill bodies trimmed under the pruner threshold; `skill` results exempt from truncation.** `compaction-tool-result-pruner` gained an `exemptTools` Config field, and the Science preset sets it to `[skill]`, so a `skill` tool result — instructions the model is meant to follow in full — is never head/tail-truncated once a session grows large enough to trigger pruning. Each bundled default skill's body (`scientific-visualization`, `scientific-writing`, `statistical-analysis`) was independently rewritten to fit under 8,000 characters, below the preset's 8,192-char pruner threshold, so the exemption is a second line of defense rather than the only one; nothing was deleted from a skill as a whole, only its always-loaded body shrank, with detail moved into that skill's own `references/*.md`. See [Science context budget — exempt skill pruning, shrink bundled skill bodies](../../.agents/notes/implemented/feature/2026-09-04-science-context-budget-skill-bodies-and-pruner-exemption.md).
- **Science runtime context no longer churns on every run; run-directory and result-frame guidance added.** The `science:environment` runtime context stopped re-rendering a per-run `Latest run …` line on every `run_python`/`run_r` call, so a long session no longer forces a fresh context snapshot into history on every run; run status stays available on demand through each run tool's own result and `get_science_state`. `STATIC_GUIDANCE` now states that `SCIENCE_ARTIFACT_DIR` is a fresh, private directory each run — a file written there does not survive to the next run's directory, and intermediate data belongs in a kernel variable or under `SCIENCE_STATE_DIR` unless it is a final deliverable. The `statistical-analysis` skill's `references/library_result_frames.md` adds a rule to print a result frame's columns before indexing one not yet used in the session, plus verified column names for pingouin, scipy.stats, and statsmodels result objects read from the shipped desktop environment. See [Science context churn and run-directory guidance](../../.agents/notes/implemented/bug-fix/2026-09-04-science-context-churn-and-run-directory-guidance.md).

### 已知

- **Chart Provenance drill-in has no Code/Execution-log/Messages/Environment sub-tabs.** They were removed when the artifact-authority migration took `runId`/`toolCallId`/`producerSessionId` out of the client-safe projection; `apps/web/tests/science-chart-outcome.e2e.ts` still asserts two of them and stays red pending the restore-vs-simplify decision carried in [0.1.1-rc.4](0.1.1-rc.4.md)'s 遗留 section.
- **A cross-session artifact-display collision is characterized but not fixed.** Two distinct artifacts that share a display title across sessions can render two DOM elements with the same accessible name.
- **Onboarding has no in-app telemetry switch.** Its copy says telemetry can be disabled at any time, but this release exposes only the `DSH_TELEMETRY_DISABLED` environment variable, not an in-app control.
- **Receiver rate limiting reads but does not retain the client IP.** The Cloudflare Worker uses the IP only as the rate-limit key, does not log or store it, and permits 20 requests per 60 seconds for each IP within one Cloudflare location, counted eventually consistently; the threshold is not runtime-configurable.
- **The DMG is arm64-only.** No x64 build is produced for this release.
- **A nature-figure-style color palette was evaluated and deferred**, separately from the bundled `scientific-visualization` skill's own Nature-journal style preset and palette reference.

## 实机验了什么

`0.1.0` carries forward the delta pass rc.4's own record already documents (2026-09-03 late night, against a DMG rebuilt from `0466780272` after the three 修复 fixes named above landed) unchanged; see [0.1.1-rc.4](0.1.1-rc.4.md)'s 实机验了什么 table for the per-item results.

One additional exploratory manual session ran on 2026-09-04 from about 01:00 to 02:10, against a DMG built from `88c43d7d09`, informal rather than checklist-keyed: "画一张分组箱线图" (draw a grouped boxplot) followed by "帮我做个 t 检验" (help me run a t-test), both on the MIMIC-IV workspace.

Observed: both bundled skills (`scientific-visualization`, `statistical-analysis`) triggered from the Chinese prompts and loaded before either turn wrote code; the workspace CSV loaded through `run_python` and the resulting DataFrame was reused across turns, with Kernel #1 unchanged throughout; the figure self-checked with `read_image`, a legend overlap found on the first draft was fixed in v2, and the final artifact was annotated; the statistics turn checked skew and variance, ran a Welch t-test on log10(LOS) with a Mann-Whitney robustness check, and reported effect sizes with confidence intervals; the model asked two `ask_user_question` clarifications during the session.

Two slips surfaced and were self-corrected within the session: an intermediate CSV written to one run's `SCIENCE_ARTIFACT_DIR` and then read back from the next run's directory — the exact failure mode the [context-churn and run-directory guidance fix](../../.agents/notes/implemented/bug-fix/2026-09-04-science-context-churn-and-run-directory-guidance.md) above now names in `STATIC_GUIDANCE` — and one wrong column name assumed on a pingouin result frame, the failure mode the same fix's `library_result_frames.md` reference now heads off. This session ran before that fix (and the skill-body/pruner-exemption fix) landed, so it is the evidence motivating both fixes, not a re-run confirming them: neither fix has been exercised on-device since landing, and no checklist item was re-verified in this session.

## 遗留

- **An x64 DMG.** This release ships arm64 only.
- **An in-app telemetry switch.** Disabling telemetry still requires setting `DSH_TELEMETRY_DISABLED` outside the app.
- **The Alibaba Cloud Function Compute (FC) telemetry receiver.** Not deployed or configured for this release; the Cloudflare Worker is the only receiver in production.
- **A nature-figure-style color palette**, evaluated and deferred.
- **A systematic accessibility pass.** No release to date has checked keyboard traversal order, screen-reader reading order, focus visibility, or WCAG contrast beyond incidental observation.
- **The rc.4 record's post-release queue**, unattempted since it was deferred: see [0.1.1-rc.4](0.1.1-rc.4.md)'s 遗留 section.
- **A full-checklist pass on the 0.1.0 DMG.** No pass to date has run the complete [device checklist](../product/device-checklist.md) against a DMG carrying this record's own fixes; one is needed before public distribution.
