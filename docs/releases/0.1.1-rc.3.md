# 0.1.1-rc.3

English | [中文](0.1.1-rc.3.zh.md)

## 改了什么

- **General environment install, owned outright.** Onboarding stopped offering to bind a conda-family environment already on the machine and instead installs the shipped `general` environment into a prefix PaperMachine provisions and owns itself, with an advanced custom-package-list route published the same way. See [PaperMachine owns its environment outright](../../.agents/notes/implemented/feature/2026-09-01-desktop-owns-its-environment.md).
- **Mirrors for package installs.** The environment install and `install_science_packages` both try package sources in order — TUNA, USTC, then the official `conda.anaconda.org` channel — defaulting to TUNA for a `Asia/Shanghai` timezone or Chinese system language. See the same note.
- **`install_science_packages` tool.** The Science tool roster gained a fifth tool that installs a package into the bound environment through micromamba, taking effect on that language's next kernel run. See [Science package install](../../.agents/notes/implemented/feature/2026-09-01-science-package-install.md).
- **PaperMachine brand.** The desktop build's sidebar, hero, and document-title brand slots switched from the generic DeepSeek Harness occupant to the PaperMachine wordmark and whale mark. See [PaperMachine brand](../../.agents/notes/implemented/feature/2026-09-01-papermachine-brand.md).
- **Host port persistence.** The Host launches on the port it last bound successfully instead of always requesting a fresh OS-assigned one, so browser-side `localStorage` state (panel width, session selection, artifact viewer state, and more) survives an ordinary relaunch. See [Desktop Host port persistence](../../.agents/notes/implemented/bug-fix/2026-09-01-desktop-host-port-persistence.md).
- **Minimal usage telemetry.** The desktop app reports three metadata-only events (`app.launch`, `environment.installed`, `environment.install-failed`) to build-time-configured receivers, off by default until receivers are configured. See [Desktop usage telemetry](../../.agents/notes/implemented/feature/2026-09-01-desktop-usage-telemetry.md).
- **Science preset gains web search, fetch, and plan mode.** `web_fetch` is enabled for Science alone among shipped presets (its run tools already reach the network directly), and Science composes its own plan-mode group with a Science-specific planning threshold. See [Science web search/fetch and plan mode](../../.agents/notes/implemented/feature/2026-09-01-science-web-and-plan.md).
- **Science preset gains a restricted subagent.** A spawned child starts its own kernel, cannot install packages, delegate further, message or list other agents, or enter plan mode. See [Science preset gains a restricted subagent](../../.agents/notes/implemented/feature/2026-09-02-science-restricted-subagent.md).
- **Bundled default Science skills.** The DMG ships `scientific-visualization`, `statistical-analysis`, and `scientific-writing` read-only, shadowed by any same-named project or user skill. See [Desktop bundled skills](../../.agents/notes/implemented/feature/2026-09-01-desktop-bundled-skills.md).
- **Chart element ids sanitized against multi-line figure text.** A multi-line annotation or legend label no longer breaks chart-state extraction for the whole figure; see [science-runtime](../../packages/science/science-runtime/README.md) ("A series or annotation id embeds a sanitized, truncated snippet…").
- **Deployment-level MCP tool curation.** An MCP client deployment can include/exclude/rename/describe individual tools instead of exposing a connected server's full roster unmodified. See [MCP tool curation](../../.agents/notes/implemented/feature/2026-09-01-mcp-tool-curation.md).
