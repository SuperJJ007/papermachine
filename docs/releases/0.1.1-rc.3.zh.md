# 0.1.1-rc.3

[English](0.1.1-rc.3.md) | 中文

## 改了什么

- **通用环境安装,完全自有。** onboarding 不再提供绑定机器上已有 conda 系环境的选项,而是把随包的 `general` 环境安装进 PaperMachine 自己置备并自有的前缀,进阶的自定义包列表路径也走同样的发布方式。参见 [PaperMachine 完全自有其环境](../../.agents/notes/implemented/feature/2026-09-01-desktop-owns-its-environment.zh.md)。
- **装包用的镜像。** 环境安装和 `install_science_packages` 都依次尝试包来源——TUNA、USTC、再到官方 `conda.anaconda.org` 频道——系统时区为 `Asia/Shanghai` 或系统语言为中文时默认选 TUNA。参见同一篇笔记。
- **`install_science_packages` 工具。** Science 的工具集新增第五个工具,通过 micromamba 把包装进已绑定的环境,在该语言下一次内核运行时生效。参见 [Science 装包](../../.agents/notes/implemented/feature/2026-09-01-science-package-install.zh.md)。
- **PaperMachine 品牌。** 桌面构建的侧栏、hero 和文档标题品牌位从通用的 DeepSeek Harness 占位切换成了 PaperMachine 字标和鲸鱼标志。参见 [PaperMachine 品牌](../../.agents/notes/implemented/feature/2026-09-01-papermachine-brand.zh.md)。
- **Host 端口记忆。** Host 启动时使用上次成功绑定的端口,而不是每次都请求一个全新的操作系统分配端口,这样浏览器端 `localStorage` 里的状态(面板宽度、会话选择、成果查看器状态等)能在正常重启后保留。参见 [桌面端 Host 端口持久化](../../.agents/notes/implemented/bug-fix/2026-09-01-desktop-host-port-persistence.zh.md)。
- **最小化使用统计。** 桌面应用向构建期配置的接收端上报三个只含元数据的事件(`app.launch`、`environment.installed`、`environment.install-failed`),在配置接收端之前默认关闭。参见 [桌面端使用统计](../../.agents/notes/implemented/feature/2026-09-01-desktop-usage-telemetry.zh.md)。
- **Science preset 获得联网搜索、抓取和 Plan 模式。** 在所有随包 preset 中,只有 Science 启用了 `web_fetch`(它的运行工具本来就能直接访问网络),Science 还自己组装了一份带 Science 专属规划阈值的 plan 模式组。参见 [Science 联网搜索/抓取与 Plan 模式](../../.agents/notes/implemented/feature/2026-09-01-science-web-and-plan.zh.md)。
- **Science preset 获得受限子代理。** 被派生的子代理启动自己的内核,不能装包、不能进一步委派、不能给别的 agent 发消息或列出别的 agent,也不能进入 plan 模式。参见 [Science preset 获得受限子代理](../../.agents/notes/implemented/feature/2026-09-02-science-restricted-subagent.zh.md)。
- **随包默认 Science skill。** DMG 以只读方式随包 `scientific-visualization`、`statistical-analysis`、`scientific-writing`,项目自带或用户自己的同名 skill 会盖过它们。参见 [桌面端随包 skill](../../.agents/notes/implemented/feature/2026-09-01-desktop-bundled-skills.zh.md)。
- **图表元素 id 针对多行图形文本做了脱敏。** 带换行的注释或图例标签不再拖垮整张图的图表状态抽取;参见 [science-runtime](../../packages/science/science-runtime/README.zh.md)("一个系列或注释 id 内嵌一段经过脱敏、截断的图形文本片段……")。
- **部署级 MCP 工具整理。** 一个 MCP client 部署现在可以对单个工具做 include/exclude/rename/describe,而不必原样暴露某个已连接服务器的全部工具集合。参见 [MCP 工具整理](../../.agents/notes/implemented/feature/2026-09-01-mcp-tool-curation.zh.md)。
