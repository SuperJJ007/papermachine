# 0.1.1-rc.4

English | [中文](0.1.1-rc.4.zh.md)

## 改了什么

### 新增

- **"Save as copy."** The artifact viewer can duplicate a committed version into a brand-new logical artifact, reusing the source's content-addressed bytes. See [`saveArtifactAs`](../../.agents/notes/implemented/feature/2026-09-02-science-save-artifact-as.md).
- **Restart Host menu action.** The application menu gained **Restart Host** (⌘⇧R), disabled while onboarding or Change Environment is open so it cannot navigate the onboarding window itself into the workspace.
- **Change Environment… shows the current environment.** Onboarding, opened from the menu, now shows the applied environment's id, revision, and status up front, defaults to "Reinstall" when the applied revision matches the standard declaration, and offers "Keep current environment" without stopping the Host in the meantime.
- **Host log.** Host stderr is persisted, redacted, and rotated at `<Harness home>/logs/host.log`; every error page names this path, and the launch-failure path no longer hangs behind a child process that inherited the Host's stderr pipe. See [raster-capture recovery and Host diagnostics](../../.agents/notes/implemented/bug-fix/2026-09-02-raster-capture-recovery-and-host-diagnostics.md).
- **`SCIENCE_WORKSPACE_DIR` reaches R runs too**, matching the Python-side fix (see 修复 below): both kernels can read the workspace by relative path.
- **A bounded, actionable `annotate_artifact` not-found diagnostic.** Annotating a name with no matching artifact now checks recent retained run directories (a validated, bounded scan) and, when it finds an eligible uncaptured file, names the exact `raster_artifacts` recovery call instead of returning a bare "not found." Same note as above.
- **Reconciliation health surfaces in the artifact library.** A non-modal banner names any store/session-log inconsistency `scienceLibrary`/the Files panel finds when a project is first opened. See [reconciliation surfacing](../../.agents/notes/implemented/feature/2026-09-02-science-reconciliation-surfacing.md).
- **Anonymous desktop usage telemetry.** PaperMachine sends `app.launch`, `environment.installed`, and `environment.install-failed` with a stable anonymous id stored at `~/.papermachine/.anonymous-user-id`; setting `DSH_TELEMETRY_DISABLED` to any non-empty value disables transmission. The deployed receiver is a Cloudflare Worker backed by D1; Alibaba Cloud Function Compute (FC) is not deployed or configured for this release. See [anonymous desktop usage telemetry](../../.agents/notes/implemented/feature/2026-09-01-desktop-usage-telemetry.md).

### 修复

- **Project artifact store schema v2 — artifact authority migration (P0, T1–T5).** The project artifact store became the sole authority for a version's content origin, producer, base version, and creation time; the Science Session event now carries only the store reference and a presentation snapshot. This is a coordinated set of changes: the [schema v2 migration](../../.agents/notes/implemented/architecture/2026-09-01-project-artifact-store-schema-v2.md) itself; [store↔session reconciliation with W2/W3 narrowing](../../.agents/notes/implemented/architecture/2026-09-01-artifact-store-session-reconciliation.md), later hardened against a stale-cache false-positive risk with revision-based cache invalidation; [raw-byte artifact reads over HTTP](../../.agents/notes/implemented/architecture/2026-09-01-science-artifact-raw-byte-reads.md) replacing base64 RPC, with a matching [HEAD route](../../.agents/notes/implemented/bug-fix/2026-09-02-science-artifact-head-route.md); the [`science/artifact-saved` event slimming](../../.agents/notes/implemented/architecture/2026-09-02-science-artifact-event-slimming.md) and its store-is-authority fold; the [client chart-state read path](../../.agents/notes/implemented/architecture/2026-09-02-science-client-chart-state-read-path.md); [Runtime-owned provenance writes](../../.agents/notes/implemented/architecture/2026-09-02-science-runtime-provenance-writes.md); and the [model-facing receipt field slimming](../../.agents/notes/implemented/feature/2026-09-02-science-tool-receipts-slimming.md) that followed.
- **rc.3 6.3 — session-restore turn/step loss.** The Science Session projection now carries its own browser-safe trajectory index (turn lifetimes and post-binding tool-call identity/turn/step), so Process view ownership no longer depends on which conversation pages happen to be loaded; reproduced and fixed against the incident's own exported session log. See [cold trajectory ownership](../../.agents/notes/implemented/bug-fix/2026-09-02-science-cold-trajectory-ownership.md). A related bug the fix uncovered — a metadata-only re-record (`annotate_artifact` after its run had settled) reassigning trace-anchor ownership to the annotate call — was found and fixed in the same investigation.
- **rc.3 9.2 — Restart Host.** Added, and disabled while onboarding is open (see 新增).
- **rc.3 2.4 — sidebar Artifacts toggle.** The entry is a genuine three-state switch: open the library, close the details panel, or return from an open document to the library, rather than getting stuck open.
- **rc.3 3.1 — kernel current directory.** The run tools' guidance no longer claims the run's current directory is its output directory (it is private, uncaptured scratch); `SCIENCE_WORKSPACE_DIR` gives both kernels a route to read the workspace by relative path.
- **rc.3 7.6 — Skill-produced PNG capture and recovery.** See the bounded annotate diagnostic under 新增, and the corrected recovery guidance in the same note.
- **An unloadable chart image now reaches a terminal failed state.** The artifact image component had no `onError` handler, so a missing or unreadable blob stayed silently broken instead of offering retry.
- **False-positive orphan classification during reconciliation.** An incomplete event-set pass no longer sets or clears the durable orphan health flag; classification stays `unverified` until a complete pass can decide it.
- **Three duplicated implementation clones removed** from the v2 reconciliation/environment-binding code.
- **A quit-time race dropped `environment.install-failed` telemetry.** `before-quit`, triggered by ⌘Q (or another app-quit path), let `app.quit()` proceed before the in-flight telemetry report's fetch completed, discarding the event at process exit. `TelemetryReporter` gained `flush()`, and `ProvisioningCoordinator`'s `beforeQuit` hook now awaits it (commit `ab6924713508`). Covered by unit tests; not yet confirmed on device with a rebuilt DMG.
- **rc.3 5.3 — chart font alias parse failure.** `FontProperties(family=<bare str>)` took matplotlib's fontconfig-pattern parse path and rejected the hyphen in `"sans-serif"`, so a generic-alias font-size edit failed as a missing font; R's `.dsh_font_available` had the matching failure for `sans`/`serif`/`mono`. A commit that resolves none of its operations now names each operation's own reason instead of one generic message, and the chart-edit panel always offers a Title row, even for a figure with no title yet. See [chart-edit font alias resolution and the titleless-figure Title row](../../.agents/notes/implemented/bug-fix/2026-09-03-chart-font-alias-and-title-row.md).
- **6.5/5.9 — save-as turn attribution and annotate-not-found guidance (new this release); rc.3 3.1/3.2 — tabular data through the kernel.** `saveArtifactAs` and a chart edit's human-edit commit now record the turn current when the viewer acted, instead of drifting onto whichever turn is newest once the trajectory next renders. The Science persona now routes a CSV/TSV/xlsx/etc. read through `run_python`/`run_r` into a named DataFrame instead of `read`/`glob`, so a later turn can reuse it. `annotate_artifact`'s description tells the model to call it on a named-but-unknown artifact and relay the diagnostic instead of fabricating a substitute file. See [viewer-write turn attribution and data-loading prompt guidance](../../.agents/notes/implemented/bug-fix/2026-09-03-science-viewer-write-turn-attribution-and-data-loading-guidance.md).
- **9.3 — kernel stdin EPIPE during teardown; 8.1 — install timeout and no-op reconciliation.** `KernelProcess` now attaches an `'error'` listener to the kernel's stdin pipe, so a write racing teardown no longer crashes the Host as an uncaught exception. `install_science_packages` gained its own `installTimeoutMs` (default 15 minutes, up to one hour) instead of the shared multi-minute `timeoutMs`; a process that exits 0 inside the deadline's grace window is reported as the success it was; and an install that changes nothing appends no environment revision, while an install that reconciles a previously timed-out prefix write does. See [kernel stdin error handling and honest install-timeout reporting](../../.agents/notes/implemented/bug-fix/2026-09-03-science-kernel-stdin-error-and-install-timeout.md).

### 已知

- **2.3 深色不是 bug(偏好为 Light)。** The rc.3 fix for "window doesn't follow system dark mode" made the window's pre-paint background unconditionally follow the OS theme, which is itself a regression for a user with an explicit Light/Dark in-app preference: they saw a flash of the wrong color. The window now resolves its background from the stored `ui-theme.preference` before painting and only subscribes to OS theme changes when that preference is `system`.
- **Model-behavior items were verified on different models across the two on-device passes.** The first pass (against `bac8323a8f`) ran on `deepseek-v4-flash-vision-exp`; the second pass (against `0466780272`) ran on the default model. No behavior difference beyond what each pass's own tester note explains has been isolated to the model change specifically.
- **Chart Provenance drill-in has no Code/Execution-log/Messages/Environment sub-tabs.** They were removed when the artifact-authority migration took `runId`/`toolCallId`/`producerSessionId` out of the client-safe projection; `apps/web/tests/science-chart-outcome.e2e.ts` still asserts two of them and is red pending the restore-vs-simplify decision (遗留 below).
- **A cross-session artifact-display collision is characterized but not fixed.** Two distinct artifacts that share a display title across sessions can render two DOM elements with the same accessible name; reported during rc.4 close-out, not independently reproduced or attributed to a specific fix in this release.
- **rc.3's post-release-queue items are unchanged**: region-color edit scope (5.4), literature search year filtering (7.3), `/plan` over-exploration (7.5), the statistics skill's retries and unconfirmed installs (7.7), a nonexistent package's failure being masked by a mirror timeout (8.2), Export staying disabled (5.6), and the model switcher's placement being by design (9.1).
- **Onboarding has no telemetry switch.** Its copy says telemetry can be disabled at any time, but this release exposes only the `DSH_TELEMETRY_DISABLED` environment variable, not an in-app control.
- **Receiver rate limiting reads but does not retain the client IP.** The Cloudflare Worker uses the IP only as the rate-limit key, does not log or store it, and permits 20 requests per 60 seconds for each IP within one Cloudflare location, counted eventually consistently; the threshold is not runtime-configurable.
